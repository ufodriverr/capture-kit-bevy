# Credits

- **Design, content and code:** ufodriverr, with Claude (Anthropic) as a coding assistant.
- **Icons** (`assets/ui/icons/`): generated for this project with OpenAI image generation through the Codex CLI,
  from text descriptions of each item, building, job and creature. Original images, not traced or edited from any
  other work.
- **Sounds** (`assets/sfx/`): generated for this project with ElevenLabs Sound Effects v2 from the text prompts in
  [tools/sfx/PROMPTS.md](tools/sfx/PROMPTS.md), then trimmed and loudness-matched with `tools/sfx/process.py`
  (ffmpeg). `ui_open.ogg` was cut by hand by ufodriverr.
- **Engine:** [Bevy](https://bevyengine.org), physics by [avian](https://github.com/Jondolf/avian), content format
  [RON](https://github.com/ron-rs/ron), and the other dependencies listed in
  [THIRD-PARTY-NOTICES.md](THIRD-PARTY-NOTICES.md).
